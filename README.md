# 🌶️ 小辣椒 · 面向农村老人的方言语音陪伴机器人

> 一个能听懂方言、主动关心、会打电话、能守安全的本地方言陪伴机器人。
> 面向农村留守老人，用「方言语音 + 本地大模型」替代复杂的手机 App 操作，子女端可远程看护。

![小辣椒](xiaolajiao.png)

---

## 📌 项目简介

「小辣椒」是一套 **软硬件一体化**的农村助老陪伴系统：老人只需对着屏幕说话，系统用 **方言语音识别** 理解意图，再由 **本地大模型** 生成自然、温暖的方言回应，并通过语音朗读出来。在此基础上，叠加了 **主动照护、家庭绑定、视频通话、跌倒守护、用药提醒、天气、秦腔/影音** 等模块，形成一个「陪伴 + 看护 + 应急」的完整闭环。

核心设计目标：**老人零学习成本** —— 不用打字、不用记菜单，靠说话完成一切操作。

## ✨ 核心功能

| 模块 | 说明 |
|------|------|
| 🗣️ 方言语音交流 | 科大讯飞语音听写（流式），支持普通话 + 23 种方言（陕西话 `shanxinese` 等）；edge-tts 语音朗读 |
| 🤖 本地大模型对话 | 本地 Ollama 角色模型「小辣椒」（基于 Qwen 开源小模型 + `Modelfile.txt` 人设），回答简短口语化、带关中口音 |
| 💞 主动照护引擎 | 按时间窗口主动发起：早安问候、午餐/晚餐提醒、睡前提醒、天气关怀、回家问候；幂等设计、老人回应后子女端可见 |
| 👨‍👩‍👧 家庭绑定 + 视频通话 | 老人端生成 6 位码，子女端 `/family.html` 注册绑定；基于 WebRTC 的双向音/视频通话、来电铃声、接听/拒接 |
| 🛡️ 跌倒守护 | YOLOv8n-pose 姿态检测，疑似跌倒时弹窗确认/求助；摄像头仅在本机处理，不通过 HTTP 输出视频 |
| 💊 用药/日常提醒 | 到点语音播报，幂等去重，支持「知道了 / 过半小时 / 不用了」回应 |
| 🌤️ 天气关怀 | 接入 open-meteo 免费接口，联网返回真实天气 + 穿衣/带伞建议 |
| 🎭 秦腔 / 影音娱乐 | 秦腔戏曲、老歌、故事、广场舞、实时电台，支持本地音频与在线媒体库 |
| 🛒 语音购物流程 | 多轮对话式购物下单流程 |
| 🧠 记忆系统 | 对话记忆、陪伴记忆、记忆管理与检索、对话质量评估 |
| 🔐 本地账户 | SQLite + PBKDF2 密码哈希，数据保存在 `~/.xiaolajiao_v4/`，不随源码分发 |

## 🛠️ 技术栈

| 层级 | 技术 |
|------|------|
| 语音识别 (ASR) | 科大讯飞语音听写（流式），普通话 + 23 种方言 |
| 语音合成 (TTS) | edge-tts（微软在线语音） |
| 大模型 (LLM) | 本地 Ollama · 角色模型 `xiaolajiao`（Qwen 系列） |
| 后端 | Python 3 · `http.server` · 自研路由/会话管理 |
| 数据 | SQLite（PBKDF2 哈希，数据目录可配置 `XIAOLAJIAO_DATA_DIR`） |
| 前端 | 原生 HTML / CSS / JavaScript（无框架，老人端 + 子女端 + 跌倒页） |
| 视频通话 | WebRTC（本地 Python 信令转发） |
| 跌倒检测 | YOLOv8n-pose（Ultralytics） |
| 天气 | open-meteo 免费 API |

## 🚀 快速开始

### 环境要求

| 软件 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 运行本地服务 |
| Ollama | 最新 | 本地大模型推理 |
| 科大讯飞账号 | — | 语音听写（普通话免费额度即可跑通） |
| 浏览器 | Chrome / Edge | 需通过 `localhost` 访问以使用麦克风 |

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 创建本地角色模型

```bash
# 双击 安装并创建小辣椒模型.bat
# 或手动执行：ollama pull qwen3:4b  →  ollama create xiaolajiao -f 小辣椒/Modelfile.txt
```

### 3. 启动

```bash
# 双击 启动演示.bat（自动打开 http://localhost:8001）
# 或手动执行：
py server.py
```

### 4. 配置讯飞语音（首次）

按 [使用说明.md](使用说明.md) 开通讯飞「语音听写（流式版）」拿到 APPID / APIKey / APISecret，填入页面弹出的设置框即可开始说话对话。

## 🧩 关键设计亮点

- **幂等的主动照护**：`care_engine.py` 用 `event_key` 保证同一件事不会被重复创建，老人每 30 秒轮询一次「此刻该做什么」，服务端只给一件事，不打扰。
- **安全兜底**：大模型输出统一做 `_strip_thinking` 清理、亲属离世等敏感语境有保守拦截重试，避免幻觉造成伤害。
- **隐私优先**：账户、会话、记忆等数据全部落在本机 `~/.xiaolajiao_v4/`；跌倒检测视频不经过 HTTP，仅本机处理。
- **零依赖前端**：老人端/子女端均为原生 JS，无需构建工具，双击即可跑，便于在老旧设备上部署。
